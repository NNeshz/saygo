# Plan de contenido completo — Zero → A1

Plan maestro del nivel Zero → A1 con la misma estructura que se ve en la web:

**Módulo (tema)** → **Submódulo (subtema, 1 sesión de ~90 min)** → **Temas que se ven en esa sesión**

---

## Cómo leer este plan

- Cada **submódulo** es una sesión de ~90 min con: objetivos "Puedo…", un puente con lo que ya saben, explicación, **vocabulario de mi entorno**, una **tarea para hablar** y 18 ejercicios interactivos (plantilla en `ClassPrompt.md`).
- **Regla de oro:** en ningún submódulo se usa gramática que todavía no se enseñó.
- **Puente / conector:** palabra puente (to, for, very, too…) o conector (and, but, because…) que se introduce o se recicla en esa sesión, para que nunca dejen de practicarse.
